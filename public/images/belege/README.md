# Belege für die Branchen-Landingpages

Echte Screenshots aus der Google Search Console, **Domain und Kundenname geschwärzt**.
Datei hier ablegen (webp oder png, ca. 1200 px breit) und in `lib/seo-check/proof-data.ts`
in `BELEG_SCREENSHOTS` eintragen (src, alt, caption, width, height). Solange die Liste
leer ist, erscheint auf der Seite nichts.
